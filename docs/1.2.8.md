# SWRT-C8-600 1.2.8

修复 USB QMI 模组拨号成功后，因模组和路由器的数据封包格式不一致而无法上网的问题。通过 Linux `qmi_wwan` 工作的 USB QMI 模组会在拨号前优先协商 raw IP，并按返回的 raw IP 或 802.3 格式配置网卡。无法读取有效协商结果时，继续使用网卡当前格式。原有 QMAP、MBIM 和 PCIe 路径各自处理数据格式。

适用于使用 WT9106 扩容布局（512 MiB RAM / 128 MiB SPI-NAND）的鲲鹏 C8-600 和 C8-601。已有固件可在「系统 → SWRT 在线更新」选择「国内加速（gh-proxy.com）」获取签名 OTA；也可用发布页的 `squashfs-sysupgrade.itb` 手动升级。具体步骤见 [在线更新说明](OTA.md) 和 [安装说明](INSTALL.md)。
