# SWRT-C8-600 1.2.9

这版改进了 USB 蜂窝上联，处理模组显示已连接但 OpenWrt 没有可用地址或路由的情况。

- **MBIM**：普通 USB `cdc_mbim` 单会话由 netifd 安装模组返回的 IPv4 地址、路由、DNS 和 MTU。若会话先激活、地址稍后下发，拨号器会在后续状态检查中补发配置。
- **NCM / ECM / RNDIS**：根据数据网卡绑定的驱动选择拨号方式。补齐华为 NCM 驱动，修正使用非默认 PDP 编号时的激活与挂断。路由模式的 DHCP 接口在会话重连时刷新租约。
- **QMI**：继续按普通 USB `qmi_wwan` 模组协商结果设置 raw IP 或 802.3。
- **IPv6**：仅 IPv6 的拨号接口绑定实际网卡，双栈仍使用 IPv4 接口的设备别名。

适用于采用 WT9106 扩容布局（512 MiB RAM / 128 MiB SPI-NAND）的鲲鹏 C8-600 和 C8-601。已使用签名 OTA 的设备可在「系统 → SWRT 在线更新」选择「国内加速（gh-proxy.com）」下载并验证升级。手动升级请使用 `squashfs-sysupgrade.itb`。参见[在线更新说明](OTA.md)和[安装说明](INSTALL.md)。
