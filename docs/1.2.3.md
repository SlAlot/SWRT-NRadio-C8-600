# SWRT-C8-600 1.2.3

- 修复 1.2.1 在线更新报告「发布中没有匹配当前系统的完整固件和校验清单」的问题。发布解析与校验兼容固件自带的精简版 jq。
- 修复在线更新页右上角的「高级设置」链接，指向「系统 → SWRT 高级设置」。在新版中，旧的网络菜单链接也能打开对应页面。
- 适用于 WT9106 板卡、512 MiB RAM / 128 MiB SPI-NAND 扩容的鲲鹏 C8-600 和 C8-601。

**从 1.2.1 或更早版本升级时，请在「系统 → 备份与升级」手动上传本次的 `*-squashfs-sysupgrade.itb`。** 装好 1.2.3 后即可使用签名 OTA。详见 [安装说明](INSTALL.md)。
