# SWRT-C8-600 1.3.0

这版新增 USB 模组发送队列卡死后的自动恢复，针对模组仍被识别、拨号仍显示已连接，但数据已经发不出去的情况。

- QModem `3.4.0_rc3-r5` 读取内核的发送超时和成功发送计数。连续超时且没有发送进展时，只重拨受影响的模组，不重启模组或路由器，也不依赖外部探测地址。
- 适用于单数据网卡的 USB 路由模式：QMI、MBIM、NCM、ECM 和 RNDIS。不按模组型号限制；桥接、复用和 PCIe 不启用这项恢复。
- 重拨前再次核验接口身份和拨号状态，避免与手动停拨冲突，并设有冷却时间。保留 1.2.9 的地址接管和重连处理。

已对上述协议做模拟回归，并在真机上验证了恢复触发逻辑。此功能处理发送卡死后的恢复，不代表已消除所有掉线原因。详见 [USB 发送卡死排查记录](USB-RECOVERY.md)。

仅适用于采用 WT9106 扩容布局（512 MiB RAM / 128 MiB SPI-NAND）的鲲鹏 C8-600 和 C8-601。已支持签名 OTA 的设备可在「系统 → SWRT 在线更新」选择「国内加速（gh-proxy.com）」。升级前请备份配置；手动升级使用 `squashfs-sysupgrade.itb`，`initramfs-recovery.itb` 仅用于首刷或恢复。参见[在线更新说明](OTA.md)和[安装说明](INSTALL.md)。
