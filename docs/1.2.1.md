# SWRT-C8-600 1.2.1

- 面向采用 WT9106 板卡、扩容至 **512 MiB RAM / 128 MiB SPI-NAND** 的鲲鹏 C8-600 和 C8-601。
- 「系统 → SWRT 在线更新」接入 [公开 Releases](https://github.com/SlAlot/SWRT-NRadio-C8-600/releases)，校验 Ed25519 签名和镜像 SHA256 后，由用户确认升级。
- 包含 LAN1/LAN3 面板编号修正和升级时保留 OpenClash 开关的修复。

已运行旧版 SWRT 的同布局设备，从「系统 → 备份与升级」手动上传本次的 `*-sysupgrade.itb` 一次，即可接入后续 OTA。原厂系统的首刷流程见 [安装说明](INSTALL.md)。
